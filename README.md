# Автотесты API Яндекс Диска

Пример интеграционных тестов на Java 17 с Maven, JUnit 5 и REST Assured.

## Подготовка

1. Откройте `src/test/java/com/maksim/disk/YandexDiskApiTest.java`.
2. Вставьте OAuth-токен тестового аккаунта между кавычками в константе `TOKEN`.
3. Убедитесь, что установлены Java 17 или новее и Maven.

## Запуск

В корне проекта выполните:

```bash
mvn clean test
```

Тест создаёт папку с уникальным именем в каталоге приложений Диска, проверяет её метаданные, копирует её и затем удаляет обе папки.

API Яндекс Диска доступно по адресу `https://cloud-api.yandex.net/v1/disk`. Для создания папки используется `PUT`.

## Проверяемые запросы

- `PUT /resources` — создание папки.
- `GET /resources` — проверка метаданных.
- `POST /resources/copy` — копирование папки.
- `DELETE /resources` — удаление временных папок.

[Документация REST API Диска](https://yandex.ru/dev/disk/rest/) · [Полигон](https://yandex.ru/dev/disk/poligon/)
